Admin

Set up, run, and manage your game session.

Mobile App

  • When you start the server, you send players the link to join or they can scan the QR code off your device.
  • When all players have the link, click "open" to run the game session as the admin.
  • Players must be on the same local network (WiFi) as you to be able to join the game session.
  • If you are on a public WiFi or there is no WiFi available, then players can join the game session if they login to your hotspot network.

Admin Console

The admin console is the control centre for the game host. From here you select the game to play and configure it, manage players, and start rounds.

Console Overview

The top of the admin console gives you the option of being a player-admin or admin-only.

Each game has its own configuration panel. Choose categories, set timers, and customise game-specific options before starting.

In-Game Controls

During a game, the admin can manage the round or end it early.

Different games give the admin different responsibilities. Category Clash games allows them to regenerate the letter.

Forcing an end to the game will lose all progress in the current game and go back to the Admin Console.

View Only

View-only mode allows the admin to observe without playing.

The admin can monitor progress.

Different games give different view-only views.
