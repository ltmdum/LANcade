Undercover Agent

Find the imposter among you!

All players see the same word except the undercover agent.

Players: 3+ (recommended 4–10). No upper limit.

Rules

  • Roles: Everyone is shown the same secret word, except the undercover agent.
  • Reveal: Click "Reveal" to learn your role, then click "Ready".
  • Clues: Take turns submitting a clue word related to the secret word. The agent must bluff!
  • Danger: If anyone submits the actual secret word, the agent wins immediately.
  • Vote: Vote who you think the agent is. A unanimous vote is required; if the group can't agree, the agent has a chance to sow doubt.
  • Outcome: If the group votes for the wrong player, the agent wins. If the agent is correctly identified, they get one final guess at the secret word.

Tutorial

Each player clicks "Reveal" to see their role, then clicks "Ready" once they've read it. Civilians see the secret word; the agent learns they are the agent.
