Cross-Game Word Reuse

Some word-based games share a common word pool. When enabled, the Prevent reusing words setting prevents a word submitted in one game from being used again in any other game that shares the pool.

The admin can toggle this setting at any time from the Admin Console.

Participating Games

The following games share the word pool:

  • Category Clash: Quick Fire
  • Category Clash: Multicat
  • Last Word Standing
  • Alphabet Race

If Prevent reusing words is enabled, a word submitted in any of these games will be blocked in all of them.
