LANcade Privacy Policy

Last updated: 30 June 2026

What This App Does

LANcade is a party-game server that runs entirely on your local network. One device hosts the server; other devices on the same WiFi network connect through their browser to play. No internet connection is required during gameplay.

Information the App Collects

The app collects and processes only the following information:

  • Player names — you choose a display name when you join a game. This name is visible to other players on the same local network for the duration of the game session. It is not stored or transmitted outside your local network.
  • Gameplay data — words submitted, votes cast, scores, and other game state is held in memory on the host device while the server is running. All data is discarded when the server stops or the app is closed.

Information NOT Collected

This app does not collect, transmit, or share:

  • Personal identifiers (email, phone number, real name, address)
  • Location data (GPS or otherwise)
  • Device identifiers (IMEI, serial number, advertising ID)
  • Usage analytics or crash reports
  • Network usage data or browsing history
  • Any information that leaves your local network

The developer (ltmdum) receives no data from this app. There are no analytics SDKs, no telemetry, and no backend servers external to your own device.

Google Play Billing

The app offers an optional in-app purchase to unlock the full game set. This purchase is processed entirely by Google Play's billing system. The app itself never sees or stores your payment details. Google provides the app with a purchase receipt (a purchase token) that confirms whether the current Google account on the device owns the unlock. This token is used only to decide which set of games to enable and is never transmitted anywhere beyond the device.

Google's own privacy policy applies to the purchase transaction: policies.google.com/privacy .

Third-Party Services

The app uses no third-party analytics, advertising, or data-processing services. The only external service involved is Google Play Billing (see above), which is used solely to verify the purchase state of the app.

WebView and JavaScript

The app contains a WebView that loads the built-in admin panel (served locally from the device's own embedded server). The WebView does not add any JavaScript interface bridge (addJavascriptInterface) to native code. JavaScript is enabled only to run the app's own React-based frontend. No third-party or untrusted web content is ever loaded into the WebView.

Data Retention and Deletion

All gameplay data exists only in the device's memory while the server is running. When you stop the server or close the app, all data is immediately and permanently deleted. No data survives beyond a session.

Children's Privacy

This app does not knowingly collect any personal information from anyone, including children under 13. If no personal information is collected in the first place, none can be mishandled.

Changes to This Policy

If this policy changes, the "Last updated" date at the top will be revised. Because the app communicates with no external server, there is no mechanism to push policy updates to users — the current policy is always available at this URL.

Contact

If you have questions about this privacy policy, you can open an issue on the project's GitHub repository: github.com/ltmdum/LANcade/issues .
